SciRetrieval — Scientific Knowledge Retrieval

SciRetrieval is a scientific knowledge retrieval subsystem. It searches, normalises, resolves, and processes scientific data from multiple online providers into structured ScientificEntity objects.

Providers

SciRetrieval can query three scientific data sources:

Provider Data
NCBI (Entrez) Genes, proteins, sequences — via the NCBI E-utilities API
PubChem Chemical compounds, substances — via the PubChem PUG REST API
NIST (Chemistry WebBook) Chemical and physical property data — via HTML scraping

Each provider has a corresponding normaliser that converts raw API responses into a consistent ScientificEntity schema.

Workflow

Raw provider data
       │
       ▼
  Normalizer (per-provider adapter)
       │
       ▼
  EntityResolver (dedup, merge aliases, canonical IDs)
       │
       ▼
  SciLab (rank, deduplicate, summarize, generate context)
       │
       ▼
  Structured ScientificEntity list

Core Components

RetrievalManager

The main entry point for multi-provider queries:

from SciRetrieval import RetrievalManager

manager = RetrievalManager()
result = manager.get_data(
    query="aspirin",
    providers=["pubchem", "ncbi", "nist"],
    max_results=10,
)

Normalizer

Per-provider adapters that parse raw responses into ScientificEntity objects:

from SciRetrieval.normalizer import Normalizer

normalizer = Normalizer()
entity = normalizer.normalize("pubchem", raw_json)

SciLab

Post-processing pipeline that ranks, deduplicates, summarises, and generates context for a set of entities:

from SciRetrieval.scilab.engine import SciLab

scilab = SciLab()
result = scilab.process(entities, query="aspirin")

Cache

Multi-backend cache with conversation and dataset tiers:

from SciRetrieval.cache.cache_backend import CacheBackend

cache = CacheBackend()
cache.set("pubchem:aspirin", data, ttl=3600)
cached = cache.get("pubchem:aspirin")

CLI

fiona sire search "aspirin"                   # Search all providers
fiona sire search "BRCA1" --providers ncbi     # Search specific provider
fiona sire classify "aspirin"                  # Classify query domain
fiona sire providers                           # List available providers
fiona sire cache clear                         # Clear result cache

Status

Fully functional. Retrieval, normalisation, entity resolution, ranking, deduplication, and context generation all work. All three providers (NCBI, PubChem, NIST) are integrated with their respective normalisers.
