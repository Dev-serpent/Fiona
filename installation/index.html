Installation

Clone the repository, create or activate a Python environment, and install Fiona in editable mode.

Quick Install Script

The fastest way to install Fiona and all dependencies (core + optional + system tools) is the install script:

git clone <repo-url> Fiona
cd Fiona
./scripts/fiona-install

The script handles everything — environment setup, pip install, optional extras (Selenium, aiohttp, EyeControl), system tool detection, and Chrome browser check for Selenium automation.

Options

Flag Description
--minimal Core only — skip browser, web dashboard, and EyeControl deps
--venv Use Python venv instead of conda
--help Show usage

Examples

./scripts/fiona-install                # Full install with conda
./scripts/fiona-install --venv         # Full install with venv
./scripts/fiona-install --minimal      # Core only

Manual Installation

Virtualenv

git clone <repo-url> Fiona
cd Fiona
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

Conda

conda create -n fiona python=3.13
conda activate fiona
git clone <repo-url> Fiona
cd Fiona
pip install -e .

The current development environment uses a conda environment named quiktieper:

source ~/Applications/miniconda3/etc/profile.d/conda.sh
conda activate quiktieper
cd /home/Dhruv/Documents/Projects/Fiona
pip install -e .

Python Dependencies

Declared in pyproject.toml:

  • cryptography
  • pynput
  • numpy
  • pandas
  • requests

LM Studio has been removed from the project — Fiona's Agent bridge now uses Ollama for local inference. Support for LM Studio was replaced in favor of the Ollama OpenAI-compatible API.

Optional extras:

  • selenium + webdriver-manager for browser automation via the BrowserAutomation module: install with pip install -e ".[browser]". A Chrome/Chromium browser must be available on the system PATH.
  • aiohttp for the web frontend (fionaLocalPages/ server). Install manually if not resolved by the main dependencies.
  • EyeControl dependencies (mediapipe, opencv-python, pyautogui): install with pip install -e ".[eyecontrol]".

SmartHome / IoT Dependencies

The IoT subsystem extends Fiona with smart home automation. These dependencies are declared in pyproject.toml under the SmartHome, HomeBackend, GNS3Automation, and Laboratory subpackages:

Package Key dependencies Role
SmartHome — (stdlib only) Core models, drivers, automation engine
HomeBackend aiohttp, paho-mqtt REST API + WebSocket + MQTT client
GNS3Automation aiohttp GNS3 REST API v2 client
Laboratory paho-mqtt Simulated device scripts and lab launcher

All dependencies are resolved automatically when you install Fiona with pip install -e ..

Recommended system tools for the lab

If you plan to use the GNS3 laboratory:

# Optional: Mosquitto MQTT broker (can also run via Docker)
sudo apt install mosquitto mosquitto-clients

# Optional: GNS3 server for full topology simulation
# See https://docs.gns3.com/docs/getting-started/installation/linux

The lab can also run standalone with Docker Compose (no GNS3 required):

# Start 9 simulated devices + Mosquitto broker
docker compose -f Laboratory/docker-compose.lab.yml up -d

System Tools

Runtime tools used by local control:

  • ydotool for pointer/keyboard automation
  • ydotoold for daemon-backed Wayland automation
  • kdotool for KDE/Wayland active-window checks
  • xdotool and xprop as fallback/legacy paths
  • tk / tkinter for GUI windows

If you plan to use browser automation, ensure Chrome/Chromium is available. webdriver-manager will automatically handle ChromeDriver:

# Selenium + webdriver-manager are installed via pip install fiona[browser]
# Chrome/Chromium must be on PATH or set via FIONA_CHROME_BINARY env var

Web Frontend

The fionaLocalPages/ SPA web dashboard has no additional build step — it is served as static files by an aiohttp Python server.

Ensure aiohttp is installed:

pip install aiohttp

Start the web frontend:

python3 fionaLocalPages/server/app.py

Open http://localhost:8765 in your browser.

Optional flags:

python3 fionaLocalPages/server/app.py --port 8080 --host 0.0.0.0 --debug

Console Script

After installation, this should work:

fiona --help

If fiona prints command not found, use the module form from the repository root:

python3 -m fiona.cli --help

Usage Examples

Once installed, try these commands:

fiona action list                # List all registered actions
fiona action run my-action       # Run a specific action
fiona browser start              # Start the Selenium browser automation
fiona browser navigate --url https://example.com
fiona voice parse "open browser" # Parse a voice phrase into an action
fiona voice listen               # Listen to microphone and execute detected action
fiona camcoms smoke-test         # Run the encryption smoke test
fiona recall remember my-key my-value --category notes
